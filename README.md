# GradReach Agent

AI-assisted research and outreach for international MSc applications. GradReach finds potential supervisors and programs, records evidence from official sources, checks funding and entry requirements against an applicant profile, prepares personalized professor emails, and manages a five-contact-per-day outreach schedule.

## Project status

The repository is initialized. The first verified phase implements the core contact and daily-queue rules. Web research, program eligibility analysis, MongoDB persistence, email-provider integration, and the user interface are planned phases and are not implemented yet.

## Requirements

- Node.js 22 or newer

## Run the core tests

```bash
npm test
```
